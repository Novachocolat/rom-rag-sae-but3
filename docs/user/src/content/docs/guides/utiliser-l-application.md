Une fois l'application ouverte, vous pouvvez suivre ce tutoriel ci-dessous, qui
explique comment vous en servir pas à pas : choisir un dossier de ROMs, lancer
une analyse, et valider les propositions de l'IA.

_Un souci pendant l'installation ? Demande de l'aide à l'équipe technique du
projet. Toute information est disponible à l'adresse suivante :
[Dépôt GitHub du projet](https://github.com/Novachocolat/rom-rag-sae-but3)_

### Étape 1 — Ouvrir l'application

La page [Premiers pas](/premiers-pas.md) vous guide dans le démarrage de
l'application. Vous devrez normalement arriver sur la page d'accueil, encore
vide, qui vous invite à choisir un dossier.
