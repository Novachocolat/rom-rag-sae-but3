Une fois l'application ouverte, suivez ce tutoriel pas à pas : choisir un
dossier de ROMs, lancer une analyse, puis valider les propositions de l'IA.

<Aside type="caution" title="Avez-vous importé les catalogues ?">
  Sans catalogue importé, tous vos jeux apparaîtront comme « non identifiés ».
  Si ce n'est pas encore fait, suivez d'abord la page [Importer les
  catalogues](../importer-les-catalogues/).
</Aside>

<Steps>

1. **Ouvrir l'application**

   La page [Premiers pas](../premiers-pas/) vous guide dans le démarrage de
   l'application. Vous arrivez normalement sur la page d'accueil, encore vide,
   qui vous invite à choisir un dossier.

</Steps>
